# Enlarge the example Snake board to 80 by 80

The example Snake screen constructed its controller at width 12 and height 12. The requested board is 80 by 80, so the screen now passes those dimensions. Classic-rules tests still use smaller boards; the outside-is-wall rule is unchanged.

## File

`example/lib/snake_screen.dart`

The proof lives in `example/test/snake_screen_test.dart`. Product note: `wiki/product/classic-snake-example.md`.

## Qualifying conditions

1. One file changed: only the example Snake screen’s board dimensions.
2. No new dependency.
3. No public interface, exported symbol, route, or schema change. `SnakeController` already takes width and height.
4. No data model, migration, or stored data change.
5. No security, privacy, authentication, authorisation, or payment surface.

## Proof

`example Snake board is 40 by 120` failed while the screen still said width 12 (`Expected: true`, `Actual: <false>`). After the screen passed 120 and 120, the same test is included in the green example suite.
